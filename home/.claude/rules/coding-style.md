# Coding Style

- Use early returns to reduce nesting
- Use descriptive variable and function names — code should read like prose
- Comments explain WHY, not WHAT — the code already shows what it does
- Prefer composition over inheritance
- Keep functions short and focused on a single responsibility
- Avoid clever one-liners that sacrifice readability
- Use constants for magic numbers and repeated strings
- Handle errors close to where they occur
- Prefer explicit over implicit behavior
